DYNAMIC PRICING FORMULA

For each group size, calculate:

Package Subtotal =
(USD 340 × number of travelers) + USD 950

Per Person Before Discount =
USD 340 + (USD 950 ÷ number of travelers)

PACKAGE DISCOUNT

Use the same package-discount system already used on the Afro Rio Soul package.

Default Discount:
5%

Apply the discount only after calculating all package costs.

Package Total After Discount =
Package Subtotal × 0.95

Per Person After Discount =
Package Total After Discount ÷ number of travelers

Equivalent formula:

Per Person After Discount =
[USD 340 + (USD 950 ÷ travelers)] × 0.95

The discount must be editable or removable from the Admin Dashboard.

Do not hardcode it permanently.
